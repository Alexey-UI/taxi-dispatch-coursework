# Реферат и презентация

Реферат содержит 37 страниц, 5 рисунков, 5 таблиц и 14 источников.

В `output/` находятся редактируемый DOCX, PDF реферата, PPTX и PDF презентации из девяти слайдов, а также отдельные титульный лист, лист задания и заявление на тему в DOCX/PDF. Исходный текст — `report.md`, собственные схемы и фактический скриншот — `assets/`, воспроизводимый генератор — `build.py`.

До сдачи необходимо заполнить ФИО, группу, сведения о руководителе, сроки и подписи; согласовать лист задания и титул с актуальным шаблоном кафедры. Эти данные не были предоставлены, поэтому в документах оставлены пустые поля.

Временная методичка явно требует начальный раздел «Аннотация», поэтому это название сохранено; весь документ именуется рефератом. Использованы поля 3/1,5/2/2 см, Times New Roman 14, интервал 1,5 и отступ 1,25 см; для таблиц/листингов применены меньший кегль и одинарный интервал. Нумерация учитывает титул/задание без печати номеров на этих листах.

Источники — официальные технические документы и сайты аналогов. Требование отзыва из примера об источниках из ЭБС необходимо уточнить. Найдена подходящая библиографическая запись: Иванова И. А., Котилевец И. Д., Хаханов И. С. «Основы построения контейнерной архитектуры современных приложений». РТУ МИРЭА, 2022, 117 с.; Лань: https://e.lanbook.com/book/240035. Полный текст в этой работе не был доступен, поэтому источник не включён как изученный. При подтверждении обязательности ЭБС автору нужно получить и изучить материалы через вузовский доступ и дополнить ссылки. Не следует указывать непрочитанный источник как прочитанный.

Проверка оригинальности выполняется автором в требуемой вузом системе. Готового отчёта антиплагиата и обещанного процента нет. Содержание основано на собственном коде, схемах и реальных испытаниях; результаты облачного запуска не выдуманы.

## Пересборка
```sh
python -m pip install -r report/requirements.txt
python report/build.py
```
Для экспорта PDF используйте LibreOffice либо Word/PowerPoint. После изменений текста обновите оглавление/номера страниц и проверьте PDF визуально. `pages.json` фиксирует номера текущей проверенной вёрстки, не является динамическим полем Word.
