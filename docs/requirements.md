# Требования и согласованный объём

Тема: «Настройка и администрирование системы автоматической обработки и распределения заказов для службы такси».

## Договорённости
Срок-ориентир: 1–3 дня. Сначала проект, потом реферат. Три роли: пассажир, водитель, диспетчер. Публичный наблюдатель и гостевой заказ. Автономная анимированная карта, симуляция водителей и потока заказов, отказов и дефицита машин. Назначение ближайшему свободному водителю подходящего класса; подтверждение или отказ, тайм-аут с повторным назначением. Минимальные бизнес-функции. Без оплаты, рейтингов, промокодов, Kafka, Prometheus и Grafana.

Go + JavaScript/Node.js, PostgreSQL, Redis, Nginx, Docker Compose, Kubernetes (локально k3d/K3s), Helm, GitHub CI/CD. Terraform — только заготовка облака. Нужны структурированные логи, просмотр событий, инструкции по диагностике. Будущий публичный домен и HTTPS. Облачные ресурсы и DNS пока не изменять.

## Матрица задания
| Требование | Подтверждение |
|---|---|
| Анализ предметной области | Реферат: аналоги и требования |
| Обоснование технологий | Сравнение и архитектура |
| Не менее пяти контейнеров | web, api, dispatcher, simulator, postgres, redis |
| Кластер | k3d: server + 2 agents; Kubernetes Deployment/Service/PVC/Ingress |
| CI/CD | GitHub Actions: тесты, образы, интеграция, Helm-деплой в временный кластер |
| Деплой | Compose и Helm, будущая облачная инструкция |
| Межконтейнерная сеть | HTTP, PostgreSQL, Redis; разделение сетей |
| Презентация | 8–10 слайдов, схема, демонстрация, результаты |

## Оформление
Рекомендуется до 50 страниц. Times New Roman 14; интервал 1,5; отступ 1,25 см; поля слева 3, справа 1,5, сверху/снизу 2 см. Номер страницы снизу по центру; титул и задание учитываются без напечатанного номера. Введение 1–3 страницы, три основные главы, заключение по задачам, литература, приложения. Текст от третьего лица. Ссылки [1] по первому упоминанию. Термины и сокращения раскрывать. Методичка явно требует «Аннотация», несмотря на «Реферат» в примере: название всего комплекта — реферат, начального раздела — аннотация.

В отзыве из примера: 5–20 источников, по одному из ЭБС МИРЭА, Лань, eLibrary и других ЭБС; самостоятельные схемы. Это критерии примера, актуальность не подтверждена. Данные студента/руководителя, подписи, конкретный срок и отчёт антиплагиата предоставляет автор. Отчёт антиплагиата не генерируется и процент оригинальности не обещается.

## Приёмка
Заказ проходит весь цикл; конкурентные обработчики не назначают два заказа одному водителю; отказ и истечение предложения повторяют поиск; рестарт не теряет заказы; без Redis распределение продолжается; гости видят публичные события, но не управляют симулятором; Compose запускается одной командой; Helm проверен в локальном кластере; инструкции и курсы соответствуют коду.
